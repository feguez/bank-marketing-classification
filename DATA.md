# Data

This project uses the **Bank Marketing** dataset from the UCI Machine Learning Repository.

The dataset contains 45,211 observations from direct marketing campaigns conducted by a Portuguese banking institution. The classification objective is to predict whether a client subscribes to a term deposit.

## Source

UCI Machine Learning Repository - Bank Marketing  
Dataset ID: 222  
DOI: 10.24432/C5K306

The dataset is licensed under the Creative Commons Attribution 4.0 International (CC BY 4.0) license.

## File Used

The analysis uses the full 45,211-observation version of the dataset and expects the local file:

`bank_marketing_data.csv`
